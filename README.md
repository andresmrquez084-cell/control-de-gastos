# Control de Gastos

Aplicación web personal para controlar ingresos, gastos, activos, pasivos, cuentas y comprobantes.

## Stack
- Frontend estático / PWA
- Supabase Auth + Database + Storage
- Preparada para Vercel

## Funciones actuales
- Registro e inicio de sesión
- Ingresos y gastos
- Activos y pasivos
- Cuentas y wallets
- Comprobantes privados
- Dashboard mensual
- Instalación como app desde el teléfono

El backend utiliza un proyecto Supabase separado para esta aplicación.
